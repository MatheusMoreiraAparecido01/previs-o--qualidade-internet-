# Projeto de Qualidade da Internet

## Objetivo
Desenvolver uma página para avaliar a qualidade de uma conexão com a internet.

## Funcionamento
O usuário informa:
- Velocidade de download (Mbps)
- Velocidade de upload (Mbps)
- Ping (ms)

O sistema estima a qualidade da conexão e apresenta uma classificação.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Resultado esperado
Ajudar o usuário a compreender a qualidade da sua conexão com a internet.
